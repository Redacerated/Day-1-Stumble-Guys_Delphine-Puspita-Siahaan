# Day-1-Stumble-Guys_Delphine-Puspita-Siahaan

Nama : Delphine Puspita Siahaan

Deskripsi :
Peserta diwajibkan membuat repository pada platform GitHub dengan status Public sebagai tempat penyimpanan dan dokumentasi selama mengikuti kegiatan workshop.
Repository ini digunakan untuk mengumpulkan berbagai dokumentasi kegiatan, materi yang disampaikan, catatan pembelajaran, serta hasil praktik selama workshop berlangsung. Melalui misi ini, peserta diharapkan dapat memanfaatkan GitHub sebagai media penyimpanan, pengelolaan, dan publikasi dokumentasi proyek secara daring.

Misi ini dilaksanakan dengan tujuan sebagai berikut:
- Memperkenalkan peserta pada platform GitHub sebagai sarana penyimpanan dan pengelolaan dokumentasi secara daring.
- Melatih peserta membuat dan mengelola repository dengan visibilitas Public.
- Membiasakan peserta mendokumentasikan materi dan kegiatan selama workshop berlangsung.
- Meningkatkan kemampuan peserta dalam menyusun catatan dan mengelola file secara terstruktur.
- Melatih peserta menggunakan file README.md sebagai dokumentasi utama repository.
