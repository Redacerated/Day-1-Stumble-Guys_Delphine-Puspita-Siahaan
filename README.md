# Day-1-Stumble-Guys_Delphine-Puspita-Siahaan

## Nama : Delphine Puspita Siahaan

## Deskripsi :
Repository GitHub ini dikembangkan secara khusus sebagai pusat penyimpanan digital untuk mendokumentasikan seluruh rangkaian proses belajar, eksplorasi materi, serta pengerjaan proyek penugasan harian. Di dalam repository ini, seluruh catatan penting dari sesi pemaparan teori hingga sesi praktik langsung dihimpun secara sistematis agar mudah diakses, dievaluasi, dan ditinjau kembali di kemudian hari.


## Tujuan Repository:
- Arsip Belajar yang Terstruktur: Berfungsi sebagai tempat penyimpanan terpusat untuk mengorganisir berbagai catatan teknis, baris kode, dan berkas pendukung yang dipelajari selama acara berlangsung.
- Media Refleksi dan Evaluasi: Membantu dalam merekam progres pemahaman materi harian melalui catatan poin-poin penting serta opini pribadi terhadap tantangan proyek yang ddiberikan.
- Memenuhi Standar Penugasan: Dibuat untuk mematuhi seluruh instruksi teknis dan administratif yang telah ditetapkan oleh panitia penyelenggara sebagai salah satu syarat kelulusan atau penilaian kegiatan.
- Sarana Latihan *Version Control*: Menjadi media aplikatif untuk membiasakan diri menggunakan alur kerja *Git* dan *GitHub* secara profesional dalam mengelola dokumen proyek.

## Dokumentasi kegiatan workshop :
* Konsep Merdeka Belajar – Kampus Merdeka (MBKM) memberikan hak kepada mahasiswa untuk belajar di luar program studi hingga 2 semester dengan pengakuan 20 SKS per semester.
* Terdapat 8 bentuk kegiatan pembelajaran MBKM, termasuk pertukaran pelajar, magang, asistensi mengajar, penelitian, proyek kemanusiaan, wirausaha, proyek independen, dan membangun desa.
* MSIB (Magang dan Studi Independen Bersertifikat) adalah program unggulan berdurasi 1 semester yang bekerja sama dengan mitra industri terbaik dan memberikan sertifikat resmi.
* Metode pembelajaran yang digunakan meliputi Project-Based Learning, Problem-Based Learning, dan Case-Based Learning untuk melatih pemecahan masalah serta keterampilan praktis.
* Program ini memberikan manfaat nyata bagi mahasiswa politeknik untuk mendapatkan pengalaman kerja, membangun jejaring profesional, serta mengasah kompetensi yang relevan dengan kebutuhan industri.
* Alur pendaftaran meliputi pengecekan data PDDikti, pembuatan akun di portal Kampus Merdeka, pemilihan program, seleksi, hingga proses konversi SKS dengan bimbingan dosen.

## Git & Hub
* Pengenalan konsep dasar penggunaan AI melalui Prompt Engineering yang efektif dengan struktur yang jelas seperti Role, Task, Context, dan Format.
- Definisi Git sebagai sistem pengatur versi terdistribusi (Version Control System) untuk melacak perubahan file, serta GitHub sebagai platform berbasis web untuk penyimpanan repository secara online dan kolaborasi.
- Memahami alur kerja Git (Git Workflow) yang melibatkan Working Directory, Staging Area, hingga Git Directory/Repository.
- Perintah esensial dasar pada Git seperti git init, git add, git commit, git clone, hingga konfigurasi identitas pengguna.
- Perintah untuk menghubungkan proyek lokal ke GitHub melalui remote, push, dan pull.
- Proses pengaturan awal (setup) mulai dari instalasi Git, konfigurasi Visual Studio Code (VS Code), hingga pembuatan dan penambahan kunci SSH (SSH Key) untuk autentikasi keamanan ke GitHub.
- Panduan praktik pembuatan proyek aplikasi sederhana (Student Task Planner) menggunakan bantuan AI, pengelolaan versi menggunakan Git, serta penyimpanan ke GitHub secara berkala.
